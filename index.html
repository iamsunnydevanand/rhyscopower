🔐 GitHub Setup for Permanent Save

Admin panel se changes permanent karne ke liye GitHub Token chahiye.

  1. GitHub.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. "Generate new token" click karein
  3. Note: "rhysco-website" likhein
  4. Scopes me "repo" select karein
  5. Generate karein aur token copy karein

⚡ Note: Token sirf aapke browser me save hoga. Ye secure hai.
